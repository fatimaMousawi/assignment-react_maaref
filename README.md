# NovaShop React Product Store

## Assignment requirements covered
- JSX
- 3+ reusable components
- Props: ProductList passes product data to ProductCard
- useState
- useEffect
- useContext via ThemeContext
- Redux Toolkit + React Redux for global cart state
- .map() for products, categories and cart
- onClick/onChange event handling
- Conditional rendering
- Form with search/filter controls
- React Router: Home, Products, Cart
- API fetch: Fake Store API
- Responsive CSS with 1024px and 768px breakpoints

## Run
npm install
npm run dev

API: https://fakestoreapi.com/products
